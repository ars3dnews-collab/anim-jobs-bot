# Animation Jobs Bot

Телеграм-бот вакансий для 3D-аниматоров.

Источник — публичная таблица [Animation/VFX/Game Industry Job Postings][sheet].
Бот читает её CSV-выгрузку, отбирает вакансии по анимации, переводит на
русский и публикует по одной в канал.

[sheet]: https://docs.google.com/spreadsheets/d/1eR2oAXOuflr8CZeGoz3JTrsgNj3KuefbdXJOmNtjEVM/htmlview

## Как это работает

* Расписание GitHub стучится в бота часто, но ритм держит сам бот: пауза
  между постами отсчитывается от времени прошлой публикации.
* Ночью (по умолчанию с 23:00 до 8:00 по времени владельца) канал молчит.
* Каждая вакансия выходит один раз. Ключ считается по студии, должности и
  ссылке и хранится в `posted.json` прямо в репозитории — поэтому память
  переживает и перезапуск, и отмену задания.
* Память пишется сразу после каждого поста, а не в конце запуска.

## Настройки

Всё в `config.py`:

| Что | Параметр |
|---|---|
| Какие должности ловить | `WANT`, `SKIP` |
| Не публиковать старее | `MAX_AGE_DAYS` |
| Пауза между постами | `POST_EVERY_MINUTES` |
| Тихие часы | `ACTIVE_HOURS`, `UTC_OFFSET_HOURS` |
| Догон при первом запуске | `BACKFILL_DAYS` |

## Секреты репозитория

`BOT_TOKEN`, `CHANNEL_ID`, `GEMINI_API_KEY`.

## Ручной запуск

Actions → Animation Jobs Bot → Run workflow:

* **dry run** — показать в логе, что нашлось, ничего не публикуя;
* **force** — опубликовать немедленно, не глядя на паузу и на ночь.
